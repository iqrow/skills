# Prior art: copy-paste prompt

For any chat AI with web search (ChatGPT, Claude, Gemini, Perplexity). Use it for one goal or problem you already have context on. Fill in the brackets; omit fields that do not apply.

```text
I'm working on [what you're building or doing]. I want to [outcome or decision], within [constraints]. My current approach is [approach, if any]. What's going wrong: [observable symptom and numbers, if any]. So far I've tried: [previous attempts]. An optional field map is available at [link or file, if you have one].

Before choosing an approach or tuning anything else:
1. State the goal and constraints. Which words are my own, and what do practitioners call those things? Give at least two plausible categories to investigate.
2. If a relevant field map is available, inspect only the matching parts, nearby concepts and catalogues for vocabulary, alternatives and source leads. Treat it as an index, not proof or a limit on the search. If no map or relevant branch is available, continue without one; don't build a map for this question.
3. Search the web for established approaches to each category, including alternatives beyond the map. Use at least three kinds of source (books, talks, practitioner blogs or videos, reference docs, case studies, forums, neighbouring fields), and include at least one practitioner. Open the underlying sources, including any suggested by the map. For each approach, explain the problem it solves, its rule or formula, who uses it, how it fails, and the link.
4. Did any of this already appear earlier in our conversation or in my notes, without being applied? Point to where it appeared.
5. Which model am I using now, if any? Which approach best fits my goal and constraints, and what would adopting it cost?
6. Give me one small experiment to decide, and what result I should look for. Link the relevant map branch as optional context if available. Propose any useful field-level map additions separately, without my project details.

Lead with the decision: adopt, switch, keep, or test. Mark anything you didn't find a source for as unverified.
```
